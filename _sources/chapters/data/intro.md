# 数据和类型

本章将介绍 OCaml 的一些内置数据类型，包括列表、变体、记录、元组和选项。其中许多你可能已经感到熟悉，因为类似的类型在其他编程语言中也很常见。具体来说：

- **列表**和**元组**与 Python 中的类似；
- **记录**和**变体**与 C 或 Java 中的 `struct` 和 `enum` 类似。

由于这些相似性，我们称之为*标准*数据类型。此外，我们还会学习*模式匹配*——这个特性你可能不太熟悉。

学完列表之后，我们会暂时放下标准数据类型，转而学习如何用 OUnit 在 OCaml 中进行单元测试。OUnit 是一个单元测试框架，类似于你在其他语言中可能用过的框架。我们之所以在这里介绍 OUnit，是因为它依赖于列表。

本章后半部分会介绍一些在其他语言中不那么常见的 OCaml 数据类型，包括：

- **选项**，与 Java 中的 `null` 有一定关联；
- **关联列表**，基于列表和元组的轻量级映射（字典）实现；
- **代数数据类型**，可以说是 OCaml 中最重要的类型，也是许多其他内置类型的基础；
- **异常**，一种特殊的代数数据类型。
