# 总结

列表是 OCaml 中非常有用的内置数据结构。OCaml 提供了构建列表的轻量级语法，而不需要你通过库来使用它们。访问列表的各个部分需要使用模式匹配，这是一项非常强大的语言特性（从它相当长的语义说明中也能看出来）。随着课程推进，我们还会看到模式匹配的更多应用场景。

OCaml 的内置列表以单链表实现。当你的需求超出中小型列表时，了解这一点就很重要。作用在长列表上的递归函数会消耗大量栈空间，此时尾递归就变得至关重要。如果你需要处理非常大的列表，可能根本不应该使用链表，而应该选择一种能更好利用内存局部性的数据结构。

OCaml 提供了多种数据类型：变体（"之一"类型）、元组和记录（"兼具"类型）以及选项（"可能"类型）。模式匹配不仅可以用来访问这些数据类型中的值，也可以用在 let 表达式和函数中。

关联列表结合了列表和元组，提供了一种轻量级的字典实现。

变体是一项强大的语言特性，是函数式语言中表示数据的主力。OCaml 的变体实际上将几个在理论上独立的语言特性集于一身：和类型、积类型、递归类型以及参数化（多态）类型。其结果是它能够表达丰富多样的数据形式，包括列表、选项、树，甚至异常。
