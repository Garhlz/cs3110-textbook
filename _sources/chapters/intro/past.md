# OCaml 的过去

若按编程语言的谱系追溯，OCaml 所属的这一大家族以 Lisp 为先祖，现代成员还包括 Clojure、F#、Haskell 和 Racket。

OCaml 源自 Robin Milner 等人在苏格兰爱丁堡计算机科学实验室开展的研究。20 世纪 70 年代末到 80 年代初，他们正在研制定理证明器。这类工具传统上以 Lisp 等语言实现，却有一个让 Milner 反复头疼的问题：证明器偶尔会拼出错误的“证明”（也就是根本算不上证明的东西），还宣称它有效。于是，他试图设计一种只能构造出有效证明的语言。ML 是“元语言”（Meta Language）的缩写，正是这项工作的成果。它的类型系统经过精心设计，使语言中能够构造的证明必然有效；定理证明器则写成一个负责构造证明的程序。后来，这门“经典 ML”逐渐发展为一门完整的编程语言。

20 世纪 80 年代初，ML 社区分成了两条路线：法国研究者继续开发 CAML，后来演变为 Objective CAML（OCaml）；英国和美国的研究者则开发了 Standard ML。这两种方言十分相似。2005 年，Microsoft 又推出了自己的 OCaml 变体 F#。

Milner 于 1991 年获得图灵奖，他在 ML 上的工作是获奖的重要原因。[ACM 的获奖者介绍页][turing-milner]这样评价道：

> ML 远远领先于时代。它建立在清晰且严密的数学思想之上，这些思想被精心梳理，以便能够独立研究，并相对容易地重新组合和复用。ML 影响了许多实用语言，包括 Java、Scala 和 Microsoft 的 F#。事实上，任何严肃的语言设计者都不应忽视这个优秀设计的范例。

[turing-milner]: https://amturing.acm.org/award_winners/milner_1569367.cfm
