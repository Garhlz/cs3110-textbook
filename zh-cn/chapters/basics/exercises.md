{{ ex3 | replace("%%NAME%%", "fib fast")}}

你的 `fib` 实现计算第 50 个斐波那契数的速度有多快？如果几乎瞬间就算出来了，那很好；但大多数人最先想到的递归解法，看起来会像是一直卡在那里。问题在于，那个显而易见的解法会反复计算子问题。例如，计算 `fib 5` 需要计算 `fib 3` 和 `fib 4`；而如果这两个值分别单独去算，就会有大量工作被重复做了（事实上是指数级的重复）。

请实现一个只需要线性工作量的函数 `fib_fast`。*提示：* 写一个递归辅助函数 `h : int -> int -> int -> int`，其中 `h n pp p` 定义如下：

- `h 1 pp p = p`
- 对任何 `n > 1`，都有 `h n pp p = h (n-1) p (pp+p)`

`h` 的思路是：假设前两个斐波那契数分别是 `pp` 和 `p`，然后继续向前计算 `n` 个数。因此，对任何 `n > 0`，都有 `fib n = h n 0 1`。

找出第一个使 `fib_fast n` 为负数的 `n` 值。这表明发生了整数溢出。
