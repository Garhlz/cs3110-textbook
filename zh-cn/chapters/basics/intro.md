# OCaml 基础

本章将介绍 OCaml 的一些基础特性。不过，在正式开始学习 OCaml 之前，先来看一个更大的话题：如何学习一门语言。

本课程的一个次要目标，不只是让你学会一门新的编程语言，更是提升你学习“如何学习”新语言的能力。

学习一门语言有五个关键组成部分：语法、语义、习语、库和工具。

**语法。** 我们说的*语法*，是指一门语言中什么样的文本才算形式正确的程序，也包括关键字、空白与排版限制、标点、运算符等规则。学习一门新语言时，最让人烦躁的事情之一，往往就是它的语法和你已经熟悉的语言不太一样。但你学的语言越多，就越容易接受“语言的语法就是这样”，而不会总想着它本来应该长成别的样子。（如果你想见识一些语法特别古怪的语言，可以看看 [APL][tryapl]，它甚至需要专门的扩展键盘；还可以看看 [Whitespace][whitespace]，它的程序完全由空格、制表符和换行组成。）要想和计算机交流，首先就必须理解语法。

**语义。** 我们说的*语义*，是指决定程序行为的规则。换句话说，语义关注的是程序的含义，也就是某段语法究竟表示了什么计算。注意，虽然英文 `semantics` 形式上是复数，但我们把它当作单数使用，这一点和 `mathematics`、`physics` 类似。

语义分成两部分：语言的*动态语义*和*静态语义*。动态语义定义程序在执行或求值时的运行时行为。静态语义定义编译时进行的检查，用来保证程序除了满足语法要求之外，在其他方面也合法。最重要的一类静态语义大概就是*类型检查*：它规定了一个程序是否类型正确。学习一门新语言时，真正困难的通常是语义，尽管语法往往是最先遇到的门槛。你需要理解语义，才能让计算机明白你的意思；而只有计算机明白了你的意思，程序才能执行出正确的计算。

**习语。** 我们说的*习语*，是指使用语言特性来表达计算时那些常见而自然的方式。同一个计算，在一门语言里往往有很多写法，那么该选哪一种？有些写法会比另一些更自然。熟练掌握这门语言的程序员，通常会偏好某些表达方式。也可以把这理解为：是否能有效运用这门语言所偏重的范式，例如命令式、函数式、面向对象等。理解习语，不只是为了让计算机明白你的意思，也是为了让其他程序员明白你的意思。代码写得符合习惯，别人就更容易读懂。

**库。** *库*是已经为你写好的代码集合。它们能让你更高效，因为很多功能不必从头自己实现。（有人说过，[懒惰是程序员的一种美德][lazy]。）学习一门新语言的一部分，就是了解有哪些库可用，以及怎样使用它们。语言通常会提供一个*标准库*，给你一组核心功能，其中很多功能如果只靠语言本身其实很难自己写出来，比如文件 I/O。

**工具。** 至少，任何语言实现都会提供编译器或解释器，作为你用这门语言和计算机交互的工具。但工具远不止这些：还有调试器、集成开发环境（IDE），以及用于分析性能、内存占用和正确性的各种工具。学会使用与一门语言配套的工具，同样能大幅提高效率。有时人们容易把工具本身和语言混为一谈。比如，如果你一直是把 Eclipse 和 Java 绑定在一起使用的，就可能意识不到：Eclipse 只是一个可以支持多种语言的 IDE，而 Java 完全可以在没有 Eclipse 的情况下使用。

在本书里学习 OCaml 时，我们主要关注的是语义和习语。当然，语法也会一路学到，但那不是最有意思的部分。我们也会接触 OCaml 标准库以及另外几个库，尤其是 OUnit（一个类似 JUnit、HUnit 等的单元测试框架）。除了 OCaml 编译器和构建系统之外，我们最主要使用的工具是顶层（toplevel），它可以让我们交互式地试验代码。
